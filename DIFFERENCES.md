### Differences from Upstream

`evil-mygo` is a standalone downstream fork diverging from the [egoist/mygo](https://github.com/egoist/mygo) upstream snapshot at commit `da8a9a1a` (snapshotted on `main` at `9b68701d`). This document tracks behavioral additions, performance/rendering fixes, framework boundary removals, and future architectural divergences relative to upstream.

> [!NOTE]
> The earlier downstream fork containing custom WebGPU and GPU surface work lives on the [`classic`](https://github.com/caelyreth/evil-mygo/tree/classic) branch.

#### Performance & Memory

- **On-demand `TextLayout` shaping release (`ui.TextLayout.Release` / `Shaped`)**: Offscreen or cold paragraphs can release cached shaped glyphs while retaining measured layout bounds and transparently re-shaping when read again ([`ui/text_layout.go`](ui/text_layout.go)).
- **Kept-layer raster scale retention (`Element.CacheScaled`)**: Allows kept cached subtrees that translate and scale together to hold their raster scale during motion instead of invalidating and re-rasterizing every frame ([`ui/cache.go`](ui/cache.go), [`ui/rasterscale.go`](ui/rasterscale.go)).
- **Exact layer transform cancellation**: Cancels a layer's own transform cleanly during painting so nested clips remain analytic instead of falling back to CPU-rasterized clip masks ([`ui/effect.go`](ui/effect.go)).
- **Lazy headless `ui.Tester` frames**: Draws headless tester frames only when the rendered image is actually read ([`ui/headless.go`](ui/headless.go)).
- **Assistive-technology awareness (`Context.AssistiveTechnology`)**: Exposes whether screen readers or assistive technology are active so views can skip constructing expensive accessibility-only subtrees when idle ([`ui/access.go`](ui/access.go), [`ui/focus_events.go`](ui/focus_events.go)).
- **Metal ring-staged `MTLBlitCommandEncoder` uploads**: Stages in-place atlas, image, and software NV12 video updates through per-slot shared staging buffers (`copyFromBuffer:toTexture:`) instead of stalling all in-flight command buffers with `waitLast()` ([`internal/gpu/metal/metal.go`](internal/gpu/metal/metal.go), [`internal/gpu/metal/video.go`](internal/gpu/metal/video.go)).
- **Dynamic `CAMetalLayer.framebufferOnly` with 60-frame hysteresis**: Keeps `framebufferOnly = YES` for TBDR/framebuffer compression unless a frame uses backdrop-reading effects, releasing back with 60-frame hysteresis and on idle trim ([`internal/gpu/metal/metal.go`](internal/gpu/metal/metal.go), [`internal/gpu/metal/present.go`](internal/gpu/metal/present.go)).
- **Effect image version diffing & backdrop-aware `pendingFrame`**: `EffectOp.Same` compares image pointers while `scene.Differ` tracks per-image `Version()` values across frames, and Metal's `pendingFrame.whole` is gated strictly on backdrop-reading effects ([`internal/scene/effect.go`](internal/scene/effect.go), [`internal/scene/damage.go`](internal/scene/damage.go), [`internal/gpu/metal/present.go`](internal/gpu/metal/present.go)).
- **1-byte `A8`/`R8` CPU clip masks & 128 MiB GPU image VRAM cap**: `raster.ClipMask` emits 1-byte `Alpha` coverage images (`A8Unorm` on Metal/D3D11 with no shader rebuild; `GL_R8`/`.r` on OpenGL), cutting clip-mask CPU memory and GPU texture footprint 4×; active uploaded images and NV12 planes are LRU-evicted past a `128 MiB` per-renderer cap in Metal, D3D11, and OpenGL ([`internal/scene/scene.go`](internal/scene/scene.go), [`internal/raster/clipmask.go`](internal/raster/clipmask.go), [`internal/gpu/metal/metal.go`](internal/gpu/metal/metal.go), [`internal/gpu/d3d11/d3d11.go`](internal/gpu/d3d11/d3d11.go), [`internal/gpu/gl/gl.go`](internal/gpu/gl/gl.go)).
- **Batch-locked glyph lookups, CoreGraphics scratch context pooling & Pango grayscale fast path**: `text.System` exposes `Lock`/`Unlock`/`GlyphLocked`/`BaselineLocked` for per-line glyph emission (`ui.paint` and `ui.Glyphs`), caches the last glyph placement, pools CoreGraphics 128×128 scratch contexts and pixel buffers on macOS (`SyscallN` hot FFI calls), and skips Pango's duplicate grayscale pre-draw once a font's monochrome glyph path is known ([`internal/text/layout.go`](internal/text/layout.go), [`internal/text/raster.go`](internal/text/raster.go), [`internal/text/coretext_darwin.go`](internal/text/coretext_darwin.go), [`internal/text/pango_linux.go`](internal/text/pango_linux.go), [`ui/paint.go`](ui/paint.go), [`ui/glyphs.go`](ui/glyphs.go)).
- **Per-frame `resolvedText` memoization & fixed-row grid measure skipping**: Caches inherited text styles per element per frame without growing `node`, short-circuits ancestor walks at already-resolved parents (guarding transient `styleFn`/transition mutations), and skips speculative height measurements in `gridLayout` when items do not align by baseline or contribute to intrinsic row tracks ([`ui/element.go`](ui/element.go), [`ui/layout.go`](ui/layout.go), [`ui/grid.go`](ui/grid.go), [`ui/paint.go`](ui/paint.go), [`ui/runtime.go`](ui/runtime.go)).
- **Direct parent state links & identity transform fast paths in hit testing**: Caches `state.parentSt` pointers during commit to eliminate `rt.states` map hashing on ancestor chains, and skips `world.Inverse()` calls when `!world.Set` in `containsScrolled` ([`ui/context.go`](ui/context.go), [`ui/runtime.go`](ui/runtime.go), [`ui/transform.go`](ui/transform.go), [`ui/input.go`](ui/input.go), [`ui/motion.go`](ui/motion.go)).
- **Single-buffer `Atlas.Repack` & LRU glyph retention in `MakeRoom`**: Replaces per-rectangle slice allocations during atlas repacking with a single contiguous staging buffer and keeps recently used glyphs and runs across `MakeRoom` calls up to half-atlas capacity instead of dropping other frames' entries immediately ([`internal/scene/atlas.go`](internal/scene/atlas.go), [`internal/text/raster.go`](internal/text/raster.go)).
- **Cached `TextLayout` span-paint metadata & `Painter.TextLayoutColors`**: Precomputes span boundary metadata on `ui.TextLayout` to eliminate per-paint `spanCache` allocations, and adds `Painter.TextLayoutColors` so retained layouts can recolor spans dynamically at paint time without re-shaping ([`ui/richtext.go`](ui/richtext.go), [`ui/text_layout.go`](ui/text_layout.go)).
- **Pre-flattened quarter-pixel `BakedPath` (`ui.BakePath` / `Painter.FillBakedPath`)**: Adds immutable `BakedPath` geometry caching device-scale flattening and all 16 quarter-pixel translation phase mask keys across frames, keeping the atlas mask fast path active under `Painter.Transform` ([`ui/path.go`](ui/path.go)).
- **Partial-repaint scene tail reuse (`engine.repaintParts`)**: Records `partMark` scene slice watermarks at the end of whole paints and truncates prior partial-frame `Glyphs`, `Stops`, `Effects`, `Wide`, and `Words` tails before repainting tracked `.Draw`/`.DrawOver` callbacks, eliminating periodic forced full-window repaints ([`ui/repaint.go`](ui/repaint.go), [`ui/paint.go`](ui/paint.go), [`ui/runtime.go`](ui/runtime.go)).
- **Cached `Layout.NextGrapheme`, `Boundaries` ASCII fast path & `TextArea.wrappedHeight` height reuse**: Exposes `Layout.NextGrapheme` over cached grapheme boundaries with binary search in `Boundaries.NextGrapheme`/`PrevGrapheme` and a pure-ASCII fast path in `Boundaries.Reset`, replacing per-query re-segmentation in `BoundsForRange`; reuses synced paragraph heights in `area.wrappedHeight` instead of re-shaping from paragraph `0` on each keystroke ([`internal/text/caret.go`](internal/text/caret.go), [`internal/text/edit.go`](internal/text/edit.go), [`ui/editor_input.go`](ui/editor_input.go), [`ui/textarea.go`](ui/textarea.go)).

#### UI, Menus & Rendering Fixes

- **Raster scale watch & exit-ghost fixes**: Resets stale scale watches and clones active scales onto exit transition ghosts ([`ui/rasterscale.go`](ui/rasterscale.go), [`ui/transition.go`](ui/transition.go)).
- **Pre-sized initial frame suppression**: Suppresses initial frames laid out before a window finishes taking its requested size ([`ui/fit.go`](ui/fit.go), [`ui/runtime.go`](ui/runtime.go)).
- **Palette swatch rows in menus (`MenuItem.Palette` / `MenuItem.Swatch`)**: Renders palette submenus as compact Finder-tag-style rows of color swatches in native macOS menus and drawn menus, carrying palette/swatch data through `platform.MenuItem` ([`menu.go`](menu.go), [`ui/menu.go`](ui/menu.go), [`internal/platform/menu.go`](internal/platform/menu.go), [`internal/darwin/menu_swatch.go`](internal/darwin/menu_swatch.go)).
- **Drawn flyout menus (`ui.FlyoutMenus`) & separator coloring**: Extends drawn popup menus and submenus beyond parent window edges in native flyouts with pre-show fit-content sizing, backdrop blur over system material, a short rise-in animation, and configurable `PopoverMenuOptions.Separator` colors ([`ui/menupresentation.go`](ui/menupresentation.go), [`ui/menuflyout.go`](ui/menuflyout.go), [`ui/popovermenu.go`](ui/popovermenu.go), [`content.go`](content.go)).

#### Platform & Tooling

- **`MYGO_LOCALE` launch-language propagation (macOS)**: Propagates `MYGO_LOCALE` at startup so AppKit system dialogs, menus, and framework strings match the configured application language ([`internal/darwin/launch_language.go`](internal/darwin/launch_language.go)).
- **`macos.icon` asset catalog support in `mygo dev`**: Compiles and packages `macos.icon` asset catalogs into development `.app` bundles ([`cmd/mygo/dev.go`](cmd/mygo/dev.go)).
- **Windows Known Folders & XDG user directories**: Resolves user home/data/config directories using standard Windows Known Folders and XDG base directory conventions ([`paths.go`](paths.go), [`paths_windows.go`](paths_windows.go), [`paths_other.go`](paths_other.go)).

#### Framework Boundary & Removals

`evil-mygo` narrows the repository strictly to a native Go UI and desktop application framework:

- **WebView & JS/TS runtime removed**: Removed `WKWebView`, `WebView2`, and `WebKitGTK` backends, `Page` / `WebView` / `ui.WebView` APIs, JS/TS IPC bridges and streaming channels, custom URL scheme handlers, cookies, browser sessions, content rules, web downloads, find-in-page, web permissions, PDF printing/text extraction, browser now-playing hooks, and TypeScript generation.
- **Node/Bun/TypeScript tooling & repo clutter removed**: Removed `packages/`, `scripts/`, `cmd/mygo/template/web`, `mygo.config.ts` configuration loading, `package.json`, `tsconfig.json`, `bun.lock`, `.bun-version`, `.claude/`, `.github/`, `AGENTS.md`, bundled agent skills, and unused `testdata/radicals.pdf`.
- **Bundled app widgets & extras removed**: Removed `ui/markdown`, `ui/editor`, `ui/richtext`, `ui/chart`, `ui/video`, `ui/netimage`, `audio/`, `document*`, plugins outside `plugins/glass`, `examples/`, `docs/`, `docs-zh/`, `website/`, and `benchmarks/`.
- **Kept intact**: Native UI & rendering core (`ui`, `internal/scene`, `internal/gpu`, `internal/raster`, `internal/text`, `internal/rope`, `plugins/glass`), application updater (`updater*.go`, `internal/update/`, `netproxy/`, `cmd/mygo` update/release tooling), native modules (`native/`, `ffi/`, `internal/nativegen`), and platform targets (`darwin`, `linux`, `windows`, `mobile`, `web` WASM).
